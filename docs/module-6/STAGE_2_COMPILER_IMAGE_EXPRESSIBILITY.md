## 1. Executive Summary

Module 6 Stage 2 implements the formal and empirical characterization layer for the compiler image:
$$\text{Img}(F) = \{ F(A) \mid A \in A_C \} \subseteq C_Q^\text{logical}$$
and its corresponding operator image $\text{OpImg}_N(F) = \{ [U_F(A)]_Q \mid A \in A_N \}$.

Stage 2 maintains three core distinctions:
1. **Three Distinct Spaces:**
   - **Primitive Gate Vocabulary ($G_\text{primitive}$):** The primitive reversible logical gates $\{X, \text{CNOT}, \text{TOFFOLI}\}$.
   - **Primitive Gate Closure ($\langle G_\text{primitive} \rangle$):** All logical circuits synthesizable from primitive gates.
   - **Compiler Image ($\text{Img}(F)$):** The subset of logical circuits generated by compilation of classical transition systems $A \in A_C$.
2. **Circuit Structural vs. Operator Semantic Identity:**
   - **Circuit Structural Identity (`CircuitStructuralIdentity`):** Exact canonical gate sequence matching ($C_1 == C_2$).
   - **Operator Semantic Identity (`OperatorSemanticIdentity`):** Unitary matrix equivalence up to global phase ($U(C_1) \equiv_Q U(C_2)$).
3. **Strict Non-Overclaiming Invariant:**
   - Injectivity: `UNPROVEN` (or `COLLISION_OBSERVED` / `NO_COLLISION_OBSERVED` for empirical samples).
   - Surjectivity: `UNPROVEN`.
   - Universal Expressibility: `UNPROVEN`.
   - Hadamard Gate $H$: Evaluated as a `TARGET CANDIDATE` and `OPEN HYPOTHESIS`. Reported as `NOT_FOUND_IN_SEARCH` or `DIMENSION_MISMATCH` within searched finite samples, never overclaiming universal non-surjectivity.
