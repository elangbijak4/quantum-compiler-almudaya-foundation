# MODULE 6 STAGE 11 TERMINOLOGY

## Core Definitions

- **Historical Lineage Record**: An immutable log object representing a single historical compilation event, referencing its Stage 10 audit report and certificate.
- **Lineage Trace Report**: An aggregated report representing the end-to-end historical provenance chain of a compiled algorithm across multiple session runs.
- **Provenance Chain Hash**: A SHA-256 cryptographic digest binding together all upstream artifacts (source program, classical model, logical circuit, context, optimization report, quality profile, audit report, and certificate).
- **Cross-Session Repository**: A persistent read-only store of historical lineage records.
