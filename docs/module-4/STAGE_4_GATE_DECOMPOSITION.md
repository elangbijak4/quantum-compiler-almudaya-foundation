## 1. Primary Objective & Central Semantic Invariant

Stage 4 transforms logical reversible circuits containing multi-controlled transformations into explicitly decomposed backend-independent circuits restricted exclusively to the frozen primitive gate set:

$$\mathcal{P} = \{ \text{X}, \text{CNOT}, \text{TOFFOLI} \}$$

### Central Semantic Invariant
$$U_{\text{Stage4}} |E(C)\rangle = U_{\text{Stage3}} |E(C)\rangle = |E(R_P(C))\rangle \quad \forall C \in D_\text{fin}$$

Stage 4 does NOT alter *what* the circuit computes; it only changes *how* multi-controlled operations are expressed.

## 3. Arity Mapping & Decomposition Strategy

| Control Count ($k$) | Gate Type | Ancilla Allocation | Decomposition Strategy |
| :--- | :--- | :--- | :--- |
| $k = 0$ | Pauli-X ($X$) | None (0 ancillas) | Primitive gate preserved directly |
| $k = 1$ | CNOT ($\text{CNOT}$) | None (0 ancillas) | Primitive gate preserved directly |
| $k = 2$ | Toffoli ($\text{TOFFOLI}$) | None (0 ancillas) | Primitive gate preserved directly |
| $k > 2$ | Multi-Controlled NOT ($C^k\text{NOT}$) | $k - 2$ workspace ancillas | Bennett Compute-Use-Uncompute Protocol |

## 4. Bennett Compute-Use-Uncompute Protocol ($k > 2$)

For a $k$-controlled operation on target $t$ with controls $c_0, c_1, \dots, c_{k-1}$:

1. **COMPUTE PHASE:**
   - Allocate clean workspace ancillas $a_0, a_1, \dots, a_{k-2}$.
   - Layer 0: $\text{TOFFOLI}(c_0, c_1, a_0)$.
   - Layer $i$: $\text{TOFFOLI}(a_{i-1}, c_{i+1}, a_i)$ for $i = 1 \dots k-2$.
2. **USE PHASE:**
   - Apply target operation: $\text{CNOT}(a_{k-2}, t)$ (or $X$/Toffoli).
3. **UNCOMPUTE PHASE:**
   - Reverse the exact compute network in opposite gate order.
   - Layer $i$: $\text{TOFFOLI}(a_{i-1}, c_{i+1}, a_i)$ for $i = k-2 \dots 1$.
   - Layer 0: $\text{TOFFOLI}(c_0, c_1, a_0)$.
4. **INVARIANT:**
   - All workspace ancillas return to $|0\rangle$ (`CLEAN`).

## 5. Ancilla Discipline & History Separation

- **Clean Ancilla Invariant:** Every workspace ancilla is declared with `initial_status = CLEAN` ($|0\rangle$) and `expected_final_status = CLEAN` ($|0\rangle$).
- **History Separation:** Logical history $H$ is a semantic configuration data register. It is strictly forbidden to use history qubits as workspace ancillas ($H \neq A$).

## 6. Verification Engine (`verify_decomposed_circuit_equivalence`)

Independently computes and verifies:
1. **Primitive Closure:** All gates belong to $\{X, \text{CNOT}, \text{TOFFOLI}\}$ with valid arities ($\le 3$).
2. **Symbolic Basis Equivalence:** $U_{\text{Stage4}} |E(C)\rangle = U_{\text{Stage3}} |E(C)\rangle = |E(R_P(C))\rangle$.
3. **Reverse Execution Equivalence:** $U_{\text{Stage4}}^\dagger |E(R_P(C))\rangle = |E(C)\rangle$.
4. **Superposition & Complex Amplitudes:** $\|\psi_\text{actual} - \psi_\text{expected}\|_2 < 10^{-12}$ and $\|U \psi\|_2 = \|\psi\|_2$.
5. **Operator Matrix Unitarity:** $\|U^\dagger U - I\|_2 < 10^{-12}$ and $\|U U^\dagger - I\|_2 < 10^{-12}$.
6. **Global Phase Preservation:** Exact computational basis state identity (zero phase shift $\phi \equiv 0 \pmod{2\pi}$).
7. **Ancilla Cleanliness:** All workspace ancillas start and end `CLEAN`.
