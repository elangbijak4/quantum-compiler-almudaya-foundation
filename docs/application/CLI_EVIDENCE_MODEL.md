# APPLICATION / PRODUCT LAYER — CLI EVIDENCE MODEL

## Claim vs Executable Evidence Invariant

> **CLAIM != EXECUTABLE EVIDENCE**

1. `STATUS: PASS` does NOT imply `CERTIFIED` unless an explicit Module 4 Semantic Certificate exists.
2. `Provider Adapter Exists` does NOT imply `Cloud Execution Occurred` unless a Stage 4/5 Execution Record exists.
3. `INCONCLUSIVE != REJECTED`.
4. `Statistical Rejection != Semantic Non-Equivalence`.

## Output Rendering Sections
- `OUTPUT`: Rendered artifact data.
- `EVIDENCE`: Core execution verification status.
- `CERTIFICATION`: Certificate details iff issuing authority issued a genuine certificate.
- `PROVENANCE`: Parent artifact identity and transformation history.
