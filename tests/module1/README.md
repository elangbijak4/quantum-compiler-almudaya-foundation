# Module 1 Tests

Tests follow the waterfall:

1. AML syntax
2. AML parsing
3. AML operational semantics
4. AML interpretation
5. UTM representation
6. AML → UTM translation
7. UTM execution
8. semantic equivalence
9. certificate generation
10. failure detection

A test passing is an empirical verification result. It is not by itself
a general mathematical proof.
